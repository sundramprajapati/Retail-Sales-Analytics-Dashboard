# Retail Sales Analytics Dashboard

End-to-end data analytics project using SQL Server and Power BI.

## What's included
- SQL Server: data cleaning, star-schema table design, advanced queries (JOINs, CTE, PIVOT, Window Functions)
- Power BI: interactive dashboard with DAX measures, Calendar table, KPIs, slicers

## Key insight
Identified that 28% of orders faced shipping delays.

## Files
- `queries.sql` — all SQL queries used for cleaning and analysis
- `dax_measures.txt` — DAX measures used in the Power BI dashboard
